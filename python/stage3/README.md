# 第 3 阶段：AI 学习教练（第 15-20 课）

## 一、先说清楚这个阶段在干嘛

前两个阶段你在学"怎么让 Python 听话"。这个阶段换个方向：

> **怎么让 AI 听话。**

具体做法是：**做一个用 AI 帮你复习的命令行工具。**

它长这样 —— 你在终端敲一句命令，它就：

```
$ python3 coach.py

📚 你有 13 篇学习记录。挑一个 14 天前学的知识点：第 8 课「字符串处理」

正在让 AI 出题...

第 1 题：下面这行代码输出什么？
    print("  Hello  ".strip().lower())
你的答案：hello

✅ 对了。strip() 先去掉两头空格，lower() 再转小写。

第 2 题：...
```

**为什么做这个，而不是又一个待办工具？**

因为待办工具你不会用 —— 你已经有 calendar-app 了。做一个自己不用的东西，就只是交作业。

这个工具不一样，它吃的是**你自己的真实数据**：

| 它读什么 | 你已经有的 |
|---|---|
| `stage1/`、`stage2/` 里的 `lessonNN_summary.md` | 13 篇，你亲手写的 |
| 每篇里「卡在哪」那一段 | 每篇必填，正好是"我还不会什么"的记录 |

AI 出的题不是从教材里抄的，是**针对你真实卡过的点**。你写的每一篇 summary，都在让这个工具变得更准。

---

## 二、这个阶段真正要练的三件事

写代码只是表面。你在这 6 节课里真正要长的能力是这三个：

### 第 1 层：会用 AI 学

大多数人问 AI 是这样的：

> ❌ "帮我写一个统计词频的函数"

拿到代码，粘贴，能跑，下一个。**你学到了零。**

应该这样：

> ✅ "我想统计词频。我的思路是用字典累加。这个思路有什么问题吗？不要给我代码。"
> ✅ "这段报了 KeyError，我以为 `d[k]` 找不到会返回 None，为什么不是？"

**区别**：前者你得到一段代码，后者你得到一个能迁移到下次的理解。

每节课都有「问 AI」环节，给你具体的提问模板。

### 第 2 层：会审 AI 的代码

这是最硬的一层，也是你现在最缺的。

你做 calendar-app 时，AI 写的代码你只能判断"能不能跑"。跑得起来 ≠ 对。有些错误要等三个月后、用户变多了、跨月了、断网了才炸出来。

每节课的「找坑」环节，我会贴一段**故意有问题的"AI 风格代码"**，让你找。这些坑不是我编的 —— 全是 AI 真实高频犯的错：

| 课 | 这节课要认的坑 |
|---|---|
| 15 | 可变默认参数（`def __init__(self, tags=[])`） |
| 16 | 用字符串切片算日期，跨月就错 |
| 17 | 请求不设 timeout，网络一卡程序永远挂着 |
| 18 | 把 API key 直接写进代码；无条件相信模型返回的是合法 JSON |
| 19 | `id = len(列表) + 1`，删过东西之后 id 就重复了 |
| 20 | 提示词注入 —— 你读进来的文本里藏了一句"忽略前面的指令" |

**认坑比写代码更值钱。** 写代码 AI 能帮你，认坑只能靠你自己。

### 第 3 层：会把 AI 当零件

前两层是"你用 AI"。这一层是**"你的程序用 AI"**。

你 calendar-app 里输入"明天下午三点交数学作业"能自动变成结构化事项 —— 那段是 AI 帮你写的，你没真正看懂它在干嘛。

这个阶段第 18 课，你会自己用 Python 写一遍。写完你会发现：**所谓"接入 AI"，就是发一个 HTTP POST 请求。** 没有魔法。

## 三、6 节课地图

每节课约 2 小时，每周 2 节，大约 3 周。

| 课 | 学什么 | 在工具里是哪一块 | 文件 |
|---|---|---|---|
| 15 | 类和对象 | `Lesson` / `Question` / `Record` 三个数据类型 | `lesson15_class.py` |
| 16 | datetime 时间处理 | "这个知识点学了 14 天了，该复习" | `lesson16_datetime.py` |
| 17 | requests 调 HTTP | 看懂"发一个请求"到底是什么 | `lesson17_requests.py` |
| 18 | 用 Python 调方舟大模型 | 让 AI 出题、判卷 | `lesson18_ai.py` |

```

17 HTTP ──→ 18 调 AI ─────────────┘
```

15、16、17 互相独立，某节卡住可以先跳过做下一节。但 **17 没通就做不了 18**，**19 没通就做不了 20**。

## 四、每节课长什么样

打开任何一个 `lessonNN_*.py`，结构都是固定的六段：

| 段 | 干什么 | 要花多久 |
|---|---|---|
| **1. 为什么这节重要** | 三个角度：对写 Python / 对用好 AI / 不学会踩什么坑 | 5 分钟，读 |
| **2. 先讲人话** | 用生活里的例子解释这个概念，不用术语 | 10 分钟，读 |
| **3. 读一读** | 示例代码，**每段下面都用注释写了输出** | 30 分钟，跟着敲 |
| **4. 练一练** ★ | 你手写，我不代写 | 50 分钟 |
| **5. 问 AI** | 「找坑」+「去问」两半 | 15 分钟 |
| **6. 自检** | 答不上来就说明这节没学透 | 10 分钟 |

**第 3 段的输出注释是这次新加的**，长这样：

```python
name = "小明"
print(f"你好，{name}")
# 输出：你好，小明

print(round(2.5), round(3.5))
# 输出：2 4        ← 不是 3 4！Python 用的是"四舍六入五取偶"
```

**这些输出都是我在你这台电脑上真跑出来的**，不是我凭印象写的。你敲完对不上，就是你敲错了 —— 直接就能发现。

唯一的例外是第 17、18 课里要联网的部分，我这边跑不了网络请求。那些会标成 `# 🌐 你会看到（大致）：`，别把它当精确答案。

## 五、开始前的准备

### 1. 装 requests

已经装好了（2.34.2）。确认一下：

```bash
python3 -c "import requests; print(requests.__version__)"
```

看到版本号就行。**不用管虚拟环境** —— 这门课不用它，理由见上级目录的 `README.md`。

### 2. 准备 API key（第 18 课才需要，现在可以跳过）

第 18 课优先使用 `stage3/.env`；若没有完整配置，会读取 `python/.env`。
需要包含 `AI_API_KEY`、`AI_API_BASE` 和 `AI_MODEL`。不要依赖或复制 `calendar-app/.env`；
优先为学习使用单独的 key。
`AI_API_BASE` 应指向支持 OpenAI 兼容 Chat Completions 的服务基础地址，也可以填写完整的 `/chat/completions` 地址。

**规则一条：key 不许写进 `.py` 文件，也不要打印或截图分享。** 写进去了就会被 git 记住，删都删不干净。`.gitignore` 已忽略 `.env`。

### 3. 心理准备

这个阶段比前两阶段难，主要难在两个地方：

**难点一：类（第 15 课）**
第一次学类，看不懂是正常的。JS 里你见过 `class`，但可能也没真写过。
建议：第 15 课的「读一读」全部敲一遍，别只看。手指记住的比眼睛记住的牢。

**难点二：程序变大了（第 19、20 课）**
前面每节课都是几十行的独立小程序。第 19 课开始，你要维护一个几百行、跨文件的东西。
会有一种"我控制不住它了"的感觉 —— 这个感觉是对的，它说明你在做真东西了。
应对办法：**一次只改一个函数，改完立刻跑一遍。** 不要一口气写 100 行再运行。

## 七、这个阶段结束时的验收

不是"代码跑通了"，是这五条：

- [ ] 工具真的能读到你写的 summary，出的题跟你学的内容对得上
- [ ] API key 在 `.env` 里，没写进代码
- [ ] 断网时程序给出一句人话提示，不是一屏红色报错
- [ ] **你能说出：换了哪句 prompt，AI 出的题变好了，为什么**
- [ ] **给你一段 AI 写的 Python，你能指出它至少一个偷懒的地方**

最后两条是这个阶段的真正目标。前三条只是达成它们的副产品。

## 卡住了怎么办

顺序没变，但第 4 步升级了：

1. **读报错最后一行**
2. **`print` 大法**：到处 `print(变量)`，看值对不对
3. **查官方文档**（不是菜鸟教程了，这个阶段开始查官方的）
4. **问 AI —— 用「问 AI」环节教你的问法**，不是"帮我改"
5. **来问我**：带上你想做什么、你的代码、完整报错
