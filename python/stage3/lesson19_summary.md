| 复习内容 | 记住什么 |

| 字典 `get()`、`len()` 和 `.items()` | `scores.get("物理", 0)` 找不到键时返回默认值 `0`；`.items()` 可以同时遍历键和值。 |

| 日期与时间差 | 两个 `date` 相减可以用 `.days` 取天数；`timedelta(days=14)` 表示 14 天的时间长度。 |
| 大模型的 `messages` | 外层列表装多条消息，每条消息是字典；`role` 表示发言者，常见值有 `system`、`user`、`assistant`。 |

课前复习题的小提醒：`q7` 中 `b = Box([])` 传入了一个独立的空列表，因此 `a.add("笔")` 后，`b.items` 仍然是 `[]`。如果 `b = Box()`，它才会和 `a` 一起使用那个可变默认列表。`q6` 的列表会显示为 `[Card(apple), Card(cat)]`，因为列表里的对象会使用各自的 `__repr__()`。

## 关键代码

### 1. 找到课程总结文件

```python
files = sorted(PY_ROOT.glob("stage[12]/lesson*_summary.md"))
```

`glob()` 按规则查找文件；`stage[12]` 表示只匹配 `stage1` 或 `stage2`，星号 `*` 表示匹配任意字符。

### 2. 用正则表达式提取课号

```python
m = re.search(r"lesson(\d+)", name)
if m:
    lesson_num = int(m.group(1))
```

正则表达式可以按模式查找文字。这里 `lesson` 匹配固定文字，`\d+` 匹配一个或多个数字，圆括号 `()` 把数字部分“捕获”起来，`m.group(1)` 取出捕获到的内容。比如文件名是 `lesson07_summary.md`，取出的文字是 `"07"`，再用 `int()` 转成数字 `7`。因为不一定每个文件名都符合规则，所以使用前要先判断 `m` 是否找到匹配结果。

### 3. 从 Markdown 表格提取知识点

```python
points = extract_table_rows(
    text,
    "练习里你能直接回顾的点",
)
```

`extract_table_rows()` 找到指定标题下的表格，过滤掉表头和分隔线，再返回知识点列表。找不到标题时返回空列表。

### 4. 生成新的、不重复的 ID

```python
def next_id(items):
    return max((item["id"] for item in items), default=0) + 1
```

先找已有记录中最大的 ID，再加一。`default=0` 表示没有任何记录时，最大值按 `0` 处理，所以新 ID 从 `1` 开始。

### 5. 把课程信息组装成列表

```python
def load_all_lessons():
    seed = json.loads(
        (HERE / "lessons_seed.json").read_text(encoding="utf-8")
    )
    result = []
    for item in seed["lessons"]:
        path = PY_ROOT / item["summary"]
        points = []
        if path.exists():
            points = extract_table_rows(
                path.read_text(encoding="utf-8"),
                "练习里你能直接回顾的点",
            )
        result.append({
            "num": item["num"],
            "title": item["title"],
            "learned": item["learned"],
            "points": points,
        })
    return result
```

这个函数读取每节课的基本信息，再尝试读取对应总结里的知识点，最后把所有课程放进一个列表。这里返回的是字典列表；练习中再把它改成 `Lesson` 对象列表。

## 踩过的坑

| 报错 / 现象 | 原因 | 怎么处理 |
| --- | --- | --- |
| 新记录的 ID 和已有记录重复 | 用 `len(items) + 1`；删除中间记录后，长度不再代表最大 ID | 找到最大 ID 再加一，并考虑空列表。 |
| 某节课没有提取到知识点 | 总结文件可能不存在，或没有目标标题和表格 | 先准备空列表；有文件时再读取和提取。 |
| 修改文件后学习日期也跟着变 | 文件修改时间记录的是最近修改，不是实际学习日期 | 从 `lessons_seed.json` 读取手动整理好的学习日期。 |
| JSON 文件损坏后读取报错 | JSON 格式不完整或不合法 | 对 `JSONDecodeError` 做明确处理，并按函数约定返回备用值。 |
| 程序写很多之后难以查错 | 一次改动太大，问题可能来自很多地方 | 一次完成一个小步骤或一个函数，改完立即运行。 |
