## 先说第 1 阶段

7 天全做完了，代码是你写的，这是最重要的。几个我看到的点：

**做得好的**
- `counts[word] = counts.get(word, 0) + 1` 这种写法你已经会主动用了，这不是初学者的写法
- 第 6 课、第 7 课的函数拆分是真的懂了 —— `input_one_student()` 里调 `get_score()` 而不是重复写输入逻辑，这个判断很对
- 第 4 课第 2 题手写 max/min 时用了 `float("-inf")` 做初始值，这个想法很干净
- 自检题你是真的在答，不是空着（第 3 课、第 4 课那几行）

**这周会专门补的**
1. **列表推导式还不是第一反应。** 第 4 课第 4 题明明要求用推导式，你写的是 for + append。两种都对，但推导式要练到顺手 —— 这周处理文件和 JSON 时，数据清洗几乎全靠它。
2. **`.isdigit()` 挡不住的东西。** 第 7 课用它验证分数，`"12.5"` 和 `"-3"` 都会被判成非法。第 11 课会给你更好的工具。
3. **`print` 和 `return` 混着用。** 第 6 课第 5 题 `fizzbuzz(n)` 里面 print，外面又 `print(fizzbuzz(n))`，所以末尾多了个 `None`。想清楚一个函数是"负责算"还是"负责显示"。
4. **别用内置名当变量名。** 第 3 课你写了 `sum = 0`，第 4 课写了 `list = [...]`。能跑，但那一行之后 `sum()` 和 `list()` 就用不了了。这类 bug 很隐蔽。
5. **第 5 课第 2 题有个真 bug。** 最后一行输出"最低科目"用的是循环结束后残留的 `subject`，不是真的最低那科；`max(scores.values())` 也在循环里被反复算。这周会有类似的题让你重做一遍。
6. **第 7 课的 `print_summary` 没写。** 需求要的是全班统计（人数、各科平均、总分最高），你写的是又循环打印了一遍每个人。这周 第 10 课、第 12 课、第 14 课都会让你补上这件事。
7. **第 7 课有个逻辑小坑。** `if name == "" or len(name) > 10: return None` —— 名字太长被当成"录入结束"了，这两件事应该分开处理。

难度按计划加了一点。第 1 阶段很顺，所以这周每天多 1-2 道题，挑战题也更硬。做不完就先做前几题，规则没变：**宁可少写不要不写。**

## 这周的三个坑，先打个预防针

**1. 路径找不到（`FileNotFoundError`）**

`open("data/notes.txt")` 里的路径不是相对于 `.py` 文件，是相对于你运行命令时所在的目录。
所以每个文件开头都写这两行，以后照抄：

```python
from pathlib import Path
HERE = Path(__file__).parent
DATA = HERE / "data"
```

**2. 中文乱码**

`open()` 一律带 `encoding="utf-8"`，`json.dump()` 一律带 `ensure_ascii=False`。
不带不会立刻报错，但文件打开一看是 `小明`，或者在别人电脑上直接崩。

**3. `except:` 什么都接**

这是这周最容易养成的坏习惯。它能让报错消失，也能让 bug 藏起来。
第 11 课会讲清楚为什么，先记住：**看到裸 `except:` 就是要改的**。
