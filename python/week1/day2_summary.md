# Day 2 学习总结

## 学习目标与真正学会的内容

| 学习目标 | 真正学会的内容（含例子） |
| --- | --- |
| 认识 `input()` 的作用，并知道它返回的值是什么类型。 | `input()` 会暂停程序，并把输入内容当做字符串返回，例如 `name = input("请输入名字：")`。 |
| 学会把 `input()` 得到的字符串转换成整数，用于计算和比较。 | `age = int(input("请输入年龄："))`，这样就可以用 `age + 1` 做计算。 |
| 会写 `if` / `elif` / `else` 条件判断。 | `if score >= 90: ... elif score >= 80: ... else: ...`。 |
| 会使用比较运算符：`==`、`!=`、`>`、`<`、`>=`、`<=`。 | `a == b` 判断相等，`a != b` 判断不相等，`a > b` 判断 `a` 是否更大。 |
| 会使用逻辑运算符：`and`、`or`、`not`。 | `if x > 0 and x < 10:`；`if score >= 60 or name == "老师":`。 |
| 会使用算术运算：`/`、`//`、`%`、`**`。 | `7 / 2` 是 `3.5`，`7 // 2` 是 `3`，`7 % 2` 是 `1`，`2 ** 3` 是 `8`。 |
| 会记住闰年规则。 | 闰年条件：能被 4 整除且不能被 100 整除，或者能被 400 整除。 |
