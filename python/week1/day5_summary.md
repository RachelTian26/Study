# Day 5 学习总结

## 学习目标与真正学会的内容

| 学习目标 | 真正学会的内容（含例子） |
| --- | --- |
| 学会定义字典并访问字典里的值。 | 字典用 `{}` 创建，例如 `student = {"name": "小明", "age": 15}`。 |
| 明确 `dict[key]` 和 `dict.get(key, 默认值)` 的不同。 | `student["name"]` 取到值，`student.get("phone", "无")` 取不到时返回默认值。 |
| 会用字典进行增、改、删、查操作。 | `student["phone"] = "13800138000"` 新增/修改，`del student["age"]` 删除。 |
| 会用 `for key in dict` 遍历键，`for value in dict.values()` 遍历值，`for key, value in dict.items()` 同时遍历键和值。 | `for key, value in student.items(): print(key, value)`。 |
| 认识列表里套字典这种真实数据结构。 | `events = [{"title": "数学作业", "done": False}, ...]`，每一项都是一个字典。 |
| 会用 `set()` 去重，并理解集合没有顺序。 | `set([3, 7, 3, 1])` 结果是 `{1, 3, 7}`，顺序不固定。 |
| 会用集合的并集、交集、差集来计算不同关系。 | `a | b` 是并集，`a & b` 是交集，`a - b` 是差集。 |
| 会用 `len(set(...))` 计算不同元素的数量。 | `len(set(class_a + class_b))` 可以算出不同学生的总数。 |
