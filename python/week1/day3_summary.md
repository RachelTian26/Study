# Day 3 学习总结

## 学习目标与真正学会的内容

| 学习目标 | 真正学会的内容（含例子） |
| --- | --- |
| 学会用 `for` 循环遍历列表、字符串和数字范围。 | `for x in [1, 2, 3]:`、`for ch in "hello":`、`for i in range(1, 6):`。 |
| 学会用 `range()` 生成一系列数字。 | `range(5)` 是 `0,1,2,3,4`，`range(1, 6)` 是 `1,2,3,4,5`。 |
| 学会用 `while` 循环重复执行代码，并控制循环结束条件。 | `while count < 5:` 会重复运行直到 `count` 变成 `5`。 |
| 理解 `break` 的作用：遇到条件时跳出整个循环。 | `if x == 3: break` 会立刻结束循环。 |
| 理解 `continue` 的作用：跳过当前这次循环，继续下一次。 | `if x % 2 == 0: continue` 会跳过当前这次，不执行后面的代码。 |
| 学会写嵌套循环，内部循环在外部循环里运行。 | `for i in range(3): for j in range(2):` 可以打印表格或矩阵。 |
| 认识循环中遍历字符串和列表的不同方式。 | 字符串每次取一个字符，列表每次取一个元素。 |

## 练习里你能直接回顾的点

| 复习点 |
| --- |
| 第 1 题：用 `for` 遍历数字或列表。 |
| 第 2 题：用 `range()` 生成连续数字。 |
| 第 3 题：用 `while` 循环做重复判断。 |
| 第 4 题：用嵌套循环处理更复杂结构。 |
| 第 5 题：用 `break` 和 `continue` 控制循环流程。 |

## 学习体会

- 今天学会循环后，觉得多条结果要用 `for` 逐行输出，`break` 和 `continue` 要用对地方。 |
