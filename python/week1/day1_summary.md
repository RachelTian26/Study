# Day 1 学习总结

## 学习目标与真正学会的内容

| 学习目标 | 真正学会的内容（含例子） |
| --- | --- |
| 学会定义变量并给变量赋值。 | 变量直接赋值即可，例如：`name = "小明"`、`age = 15`。 |
| 认识四种基础数据类型：`str`、`int`、`float`、`bool`。 | `str` 是文字，`int` 是整数，`float` 是小数，`bool` 只能是 `True` 或 `False`。 |
| 了解 `type()` 可以查看变量类型。 | `type(name)` 会显示 `<class 'str'>`，`type(age)` 会显示 `<class 'int'>`。 |
| 会用 f-string 把变量放进字符串里输出。 | 字符串前加 `f` 后，`{name}` 会被替换成变量值，例如 `f"我叫 {name}"`。 |
| 会用 `int()`、`str()` 做类型转换。 | `int("100")` 变成数字 `100`，`str(15)` 变成字符串 `"15"`。 |
| 会用 `{:.2f}` 把数字格式化成两位小数。 | `{height:.2f}` 会把 `3.14159` 输出为 `3.14`。 |
| 字符串相加是拼接，`"100" + "100"` 得到 `"100100"`，而把它们转换成整数再相加，`int("100") + int("100")` 得到 `200`。 |
