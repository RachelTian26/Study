# Day 4 学习总结

## 学习目标与真正学会的内容

| 学习目标 | 真正学会的内容（含例子） |
| --- | --- |
| 学会创建列表并给列表赋值。 | 列表用 `[]` 创建，如 `fruits = ["苹果", "香蕉", "橙子"]`。 |
| 会用索引读取和修改列表元素。 | `fruits[0]` 取第一个元素，`fruits[1] = "葡萄"` 修改第二个元素。 |
| 会用 `append()`、`insert()` 增加元素。 | `fruits.append("梨")` 在尾部添加，`fruits.insert(1, "葡萄")` 插入到指定位置。 |
| 会用 `remove()`、`pop()`、`del` 删除元素。 | `fruits.remove("葡萄")` 按值删除，`fruits.pop()` 弹出最后一个，`del fruits[1]` 按位置删除。 |
| 会用 `in` 判断列表是否包含某个值。 | `"苹果" in fruits` 返回 `True` 或 `False`。 |
| 会用切片取子列表、步长和反转列表。 | `nums[2:5]` 取第 2-4 个元素，`nums[::2]` 取步长为 2，`nums[::-1]` 反转列表。 |
| 会用 `len()`、`max()`、`min()`、`sum()` 处理列表。 | `len(nums)`、`max(nums)`、`min(nums)`、`sum(nums)` 分别求长度、最大、最小、总和。 |
| 会区分 `sort()` 修改原列表和 `sorted()` 返回新列表。 | `scores.sort()` 改变原列表顺序，`sorted(scores)` 返回新列表不改变原列表。 |
| 会用 `for` 遍历列表，必要时用 `enumerate()` 同时拿到位置和值。 | `for i, v in enumerate(fruits):` 同时取出索引和值。 |
| 会用列表推导式快速生成新列表。 | `[x**2 for x in range(1, 6)]` 可以一行生成平方列表。 |

## 练习里你能直接回顾的点

| 复习点 |
| --- |
| 第 1 题：定义列表后输出长度和首尾元素，并插入新元素。 |
| 第 2 题：用循环找最大值、最小值、总和，不依赖内置排序结果。 |
| 第 3 题：读取输入数字，排序后计算平均值并筛选高于平均值的数字。 |
| 第 4 题：用列表推导式筛选满足条件的单词并转成大写。 |
| 第 5 题：去重时保持第一次出现的顺序。 |
| 第 6 题：用切片或 `pop()/insert()` 实现列表右移。 |
