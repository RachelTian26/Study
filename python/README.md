# Python 一个月学习计划（2026-08-01 → 2026-08-31）

## 这份计划怎么用

每天打开这个文件，找到今天的日期，照着做。每天的练习文件已经建好了，里面写着题目和空函数，你只要填代码。

**每天的固定节奏（约 2 小时）**

| 时段 | 做什么 |
|---|---|
| 前 10 分钟 | 打开昨天写的文件，重读一遍自己的代码。看不懂了就说明当时没学懂，先补 |
| 中间 40 分钟 | 看教程 / 视频，**边看边跟着敲**，不要只看 |
| 后 60 分钟 | 关掉教程，做当天的练习文件。卡住先自己想 10 分钟 |
| 最后 10 分钟 | 写 `dayN_summary.md`（照 `SUMMARY_TEMPLATE.md` 的格式），然后 git commit |

**三条规则（比计划本身更重要）**

1. **练习必须自己手写。** 可以问我原理、让我看报错、让我 review 写完的代码，但不要让我代写。第 1-2 周尤其严格。
2. **卡住超过 20 分钟就来问我。** 不要死磕，也不要跳过。问的时候把你的代码和报错一起发我。
3. **宁可少写不要不写。** 某天只有 30 分钟，就做当天练习的第 1 题。断一天比断一周好补。

## 卡住了怎么办

按这个顺序：

1. **读报错最后一行**。Python 报错信息很友好，最后一行就是原因。
2. **`print` 大法**。不知道哪错了就到处 `print(变量)`，看值对不对。
3. **查菜鸟教程**。语法忘了就查，这不算作弊，专业程序员天天查。
4. **来问我**。带上：你想做什么、你写的代码、完整报错。别只说"我的代码跑不了"。
