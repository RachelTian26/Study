### 为什么第五段最重要

前面几段是记录"我会了什么"，这段是记录"我还不会什么"。

第二种信息价值高得多 —— 它决定下一周的难度怎么调、哪个知识点要重做一遍。
第 2 周 README 里那 7 条改进建议，全部来自读你第 1 周的真实代码，不是来自你的总结。
如果这一段写得实在，我就能提前发现问题，不用等到你踩坑。

写"卡在哪"不丢人。每天都顺才需要担心 —— 那说明题目太简单了。
