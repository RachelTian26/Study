第 22 课：把“秒数”收到 Python 手里

现在只做一件事：给每个声音文件量时间。后面做字幕、做视频，全靠这些秒数。

1先想清楚：今天在算什么？

📄 一个声音文件
hello.aiff
→
⏱️ 场记量时长
ffprobe
→
📨 Python 拿到数字
2.003991
→
➕ 加总
每句几秒

为什么要这个数字？因为第 23 课字幕要按秒出现，第 25 课画面要按秒翻页。今天先把时间量出来。

2不写 capture_output，等于没听见

🔊 场记对着全场喊“2 秒！”导演没记下来，等于白喊。
r = subprocess.run(probe)
print(r.stdout)   # None
📨 让场记把结果写在纸条上递过来，导演才真正拿到。
r = subprocess.run(probe, capture_output=True, text=True)
print(r.stdout)   # 2.003991\n
点左边两个按钮，看 Python 拿到什么

3纸条上的字，不是数字

场记递过来的是字："2.003991"。字和字相加，只会粘在一起。

paper = "2.003991"
print(paper + "0.4")   # 2.0039910.4

用 float() 把它翻译成数字，才能加 0.4。

seconds = float(paper)
print(seconds + 0.4)   # 2.403991
点按钮看看区别

4文件名要补零：line01 不是 line1

文件名是按“字”排队，不是按数字大小排队。不补零就会乱：

点按钮看看排队顺序
for n in [1, 2, 10]:
    print(f"line{n:02d}.aiff")

# line01.aiff
# line02.aiff
# line10.aiff

再加一句 mkdir(parents=True, exist_ok=True)：文件夹没有就建，已经有也不报错。
